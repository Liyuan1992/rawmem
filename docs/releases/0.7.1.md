# rawmem 0.7.1

rawmem 0.7.1 adds distribution metadata without changing the evidence ledger
or capture contracts.

## Added

- An official MCP Registry descriptor.
- A cross-platform UV-based MCPB bundle for the bounded, read-only
  `rawmem-mcp` server.

## Unchanged boundaries

- No automatic memory promotion.
- No MCP write tool.
- No cloud sync or upload.
- Existing event, cursor, capture, and disclosure schemas remain unchanged.
