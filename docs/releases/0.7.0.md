# rawmem 0.7.0

rawmem 0.7.0 adds an optional DeepSeek Harness interoperability boundary while
keeping the core dependency-free and the evidence ledger authoritative.

## Added

- Passive tailing of Harness `session.jsonl` and concatenated
  `session.jsonl.zstd` persistence.
- Direct user/model turn capture with injected messages and reasoning omitted.
- Tool metadata capture without tool arguments or result bodies.
- A bounded, path-free, read-only `rawmem-mcp` stdio server.
- Explicit `read:summary` and `read:full` disclosure scopes.
- Synthetic plain/Zstandard fixtures and a real MCP stdio compatibility test.

## Unchanged boundaries

- No automatic memory promotion.
- No MCP write tool.
- No cloud sync or upload.
- Existing event and cursor schemas remain unchanged.
- The new Harness tailer is disabled until explicitly enabled.
